Скриншот full_time отображает весь процесс симуляции.
Кнопка btn нажимается дважды, приемник дважды проходит цикл rx_state 0 -> 1 -> 2 -> 0.
Кадры 0 и 2 пропущены, кадры 1 и 3 приняты целиком, с самого начала.

Далее в подробностях.

Скриншот 1.
Кнопка btn нажата, программа активировала сигнал start.
1.1. Желтый маркер. Начало следующего кадра src_frame = 1: источник выставил первый пиксель и pix_sof = 1.
rx_state = 1, приемник ждет начало кадра
1.2. Синий маркер. Фронт pix_clk через 20 нс после желтого маркера (источник выставляет данные по спаду, приемник забирает по фронту).
rx_state = 2, приемник принимает данные, сигналы s_tvalid отображают появление слов на выходе FIFO и чтение их DMA
(импульсы короткие - DMA забирает каждое слово сразу, FIFO не накапливается; pix_overflow = 0, переполнения не происходит)
Кадр будет принят и записан в память

Скриншот 2.
2.1. Желтый маркер. Передача данных 1 кадра закончилась (pix_valid = 0).
rx_state = 0, приемник уснул, проснется только по фронту сигнала start
2.2. Первый синий маркер - начало передачи следующего кадра (src_frame = 2), но приемник спит, поэтому
данные не принимаются (сигналы s_tvalid отсутствуют, в FIFO и DMA ничего не поступает)
Этот кадр будет пропущен
2.3. Второй синий маркер - DMA завершил запись, программа деактивировала сигнал start.
Testbench сверил память с кадром 1 и отпустил кнопку btn.
cap_frame = -1 (FFFFFFFF) - сброшено перед вторым нажатием, то есть снова «ничего не захвачено»

Скриншот 3.
3.1. Желтый маркер. Кнопка btn снова нажата
3.2. Синий маркер. Программа снова активировала сигнал start. Приемник проснулся.
rx_state = 1, приемник готов принимать данные, но прием начнется лишь с началом следующего кадра (pix_sof = 1, start of frame)
cap_frame = -1 (FFFFFFFF), то есть по-прежнему «ничего не захвачено»

Скриншот 4.
4.1. Желтый маркер. pix_sof = 1, пришел следующий кадр (src_frame = 3)
rx_state = 1, приемник в стадии готовности.
Далее rx_state меняет состояние с 1 на 2 - прием начался,
s_tvalid отображают появление слов на выходе FIFO и чтение их DMA.
Кадр будет принят и записан в память

Общее состояние errors = 0, ошибок нет. Проверяется:
- соответствие переданных и принятых данных (все 16000 слов памяти для каждого из двух кадров);
- приемник молчит, пока кнопка не нажата;
- pix_overflow = 0 (FIFO не переполнялся).
